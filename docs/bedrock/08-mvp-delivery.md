# 基岩版 MVP 交付范围与剩余工作

依据 2026-10-28 的范围调整，优先交付当前用户已安装的 Windows 基岩版检测、系统启动、`.mcpack` / `.mcaddon` 的安全导入、安装、移除及恢复。复杂世界配置、历史版本部署、多实例与原生 Mod 暂缓，已有代码不作为 MVP 完成的证据。

## 已有实现与证据

- 安装检测和启动使用 Windows 包查询及应用激活；此前已在一台机器上看到系统接受启动请求及游戏进程。授权和登录由系统及游戏处理，激活成功不等于进入游戏。
- 文件预览、受限解压、UUID 冲突检查、事务安装、备份隔离及恢复已有实现。隔离测试覆盖单包和同时包含资源包及行为包的 `.mcaddon`，从预览到安装、移除、恢复及安装事务回滚的完整服务流程；恶意或不受支持的输入及异常恢复还有独立测试。
- 用户此前确认正式版 `1.26.5203.0` 的探针写入包在游戏列表中可见，测试包随后移回暂存并比对哈希；这不是启动器界面端到端验收，也不证明包启用或新版本兼容。

## 仍需完成

1. 在用户允许实机测试后，对当前安装版本重新确认系统启动、目标目录与关闭/同步状态，并验证启动器界面分别导入、安装、移除和恢复自制 `.mcpack`、`.mcaddon`；核对原有数据、备份及恢复记录。用户目前选择暂不进行实机测试，不能用隔离测试代替这一步。
2. 根据上述验证结果修复发现的问题，评估对应版本的目录和写入能力；在没有证据前不扩大现有版本保护，也不能宣称当前机器上的安装和卸载可用。游戏更新后需要重新验证兼容性。
3. 回归未安装、注册变化、无权限、文件被占用、扫描不完整、目标冲突和中断后的提示及恢复；对真实界面的结果保留证据，不把系统接受启动请求描述为游戏已经成功运行。
4. 回归现有 Java 的基本启动和旧配置，并核对发布所需的上游许可及第三方物料。未获得清晰分发授权前不发布。

测试与限制的详细记录见 [06-test-matrix.md](06-test-matrix.md)。所有候选目录和云端引用无法由本地检查完全证明；游戏与同步进程也不受启动器锁控制。
